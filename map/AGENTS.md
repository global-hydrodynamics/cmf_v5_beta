# Instructions for map preprocessing

Read the [root development policy](../AGENTS.md), then the shared
[preprocessing conventions](../docs/preprocessing_code_conventions.md) and the
README of the component being edited. Use the [map overview](README.md) and
[shared tools guide](tools/README.md) to find the responsible workflow.

For map-product readers/writers or interfaces, consult the existing
[metadata specification](../variable_table/map_metadata_spec.md) and
[variable registry](../variable_table/map_variables.csv); follow the root
metadata-maintenance rules. Keep map-local path/calling conventions in their
own README. Historical `map/src/` is a reference, not an automatic migration
or formatting target. Model-specific `src_main/` conventions are not imposed
on these standalone tools.
