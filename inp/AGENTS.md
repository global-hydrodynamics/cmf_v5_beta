# Instructions for runoff preparation

Read the [root development policy](../AGENTS.md), then the shared
[preprocessing conventions](../docs/preprocessing_code_conventions.md) and the
[input guide](README.md). Consult the target dataset README and
[runoff registry](runoff_datasets.csv) for its verified data contract.

For ERA5-Land work, follow the existing
[Product/Download/Convert design](download_ERA5-Land/README.md). Keep the
[KG-0019 time-attribution question](../research/records/knowledge_gaps/KG-0019.md)
open unless a separately approved scientific task resolves it. For generated
NetCDF, consult the [output conventions](../docs/netcdf_output_conventions.md).
Use the root package-data policy for external stores and generated data.
