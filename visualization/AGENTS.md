# Instructions for `visualization/`

Follow the repository-wide rules in [`../AGENTS.md`](../AGENTS.md), including
approval, branch, data, research, and Gallery-publication requirements. Use the
[development rules index](../docs/development_rules_index.md) for cross-module
work.

For visualization tasks, use the
[`cama-visualization` Skill](../.agents/skills/cama-visualization/SKILL.md),
the [repository development guide](repository_development_guide.md), the
[figure-making guideline](figure_making_guideline.md), and the
[visualization catalog](visualization_catalog.csv). The guide and guideline
are the formal component references; the catalog is a discovery/status index.
