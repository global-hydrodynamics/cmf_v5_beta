# Instructions for `tutorial/`

Follow the repository-wide rules in [`../AGENTS.md`](../AGENTS.md), including
approval, branch, data, research, and publication requirements. Use the
[development rules index](../docs/development_rules_index.md) to find guidance
for work that spans components.

For tutorial implementation, read
[`agent_tutorial_development.md`](agent_tutorial_development.md) and the target
tutorial's design specification. For learner-facing manuals, also read
[`agent_manual_authoring.md`](agent_manual_authoring.md). The human workflow is
[`how_to_develop_tutorials.md`](how_to_develop_tutorials.md).

For tutorial figures, consult the Visualization Gallery and catalog for
scientifically suitable existing methods, and apply the
[`cama-visualization` Skill](../.agents/skills/cama-visualization/SKILL.md).
Creating or reviewing a tutorial figure does not authorize Gallery publication.
