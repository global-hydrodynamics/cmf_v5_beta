## Change and result

The independent `read_bifurcations()` check in f04 used the same overly strict
`1e-5°` tolerance. It now uses `0.0006°`, matching f03b. No shared abstraction
or broader refactoring was needed. f05 already imports f03b's reader and needed
no code change.

Using the existing Mekong map, f03b rendered; the f04 Shell workflow generated
f04a, f04b, and their combined Figure; and the f05 Shell workflow generated all
six panels and their combined Figure. Outputs were redirected to `/private/tmp`
for inspection, leaving repository Figures and Map data unchanged. All three
composite images were visually reviewed.
