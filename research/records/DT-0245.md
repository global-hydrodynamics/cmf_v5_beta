# DT-0245 — Standardize Tutorial01 on NetCDF I/O

- **Date:** 2026-11-28
- **Branch:** `feature/package-builder`
- **Starting commit:** `3e37a6c4e6884c6eb5bbba9b838494d69d057143`
- **Area:** tutorial simulation workflow; learner and design documentation
- **Scope:** Update the standalone Tutorial01 workflow and its learner README, Tutorial Design, and Manual Design to use annual NetCDF runoff, the current NetCDF input matrix, daily NetCDF outputs, and a final NetCDF Restart. GOSH workflows, Tutorial02, scientific data, and model source were out of scope.

## Change and enabled capability

Tutorial01 now selects `inp/repo-mek_1deg/runoff2000.nc` (`runoff`, CF `time`) and its current paired NetCDF input matrix, enables Gregorian leap-year handling, and writes the five existing output variables plus one end-of-run Restart in NetCDF. Binary-only CTL generation was removed from this workflow. The existing 40-day Mekong experiment period, map, routing and physical settings, timestep, and single-thread non-MPI execution were retained. The README and both design documents now describe the NetCDF inputs, outputs, time coverage, and write-only Restart role consistently.

## Validation and limits

See [VR-0292](validation_runs/VR-0292.md). The shell syntax check passed. The bundled runoff file was inspected for variable, units, CF calendar, interval bounds, and leap-year records. An isolated copy of the updated script completed the 40-day simulation and produced all five 40-record daily NetCDF outputs and the final one-record NetCDF Restart. Existing Tutorial01 outputs were not used. This establishes operational behavior for the available checkout, not scientific correctness.

## Worktree note

Four pre-existing untracked files under Tutorial02 were preserved and were not modified as part of this task.

## Maintainer decision update — 2026-11-28

The maintainer revised the Runoff I/O requirement before closing this work: the
final Tutorial01 workflow keeps monthly Binary Runoff and uses NetCDF only for
the mapping matrix, model output, and Restart. The initial annual-NetCDF Runoff
trial above records the earlier direction and is superseded as the current
workflow specification. The script and three learner/design documents were
updated to the revised specification. See [VR-0293](validation_runs/VR-0293.md)
for the final Binary-Runoff execution and output checks. The 40-day experiment
period and other scientific settings remain unchanged.
