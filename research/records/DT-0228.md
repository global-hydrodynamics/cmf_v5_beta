## Prior constraint and change

The former positional descriptor combined map geometry and runoff mapping, but did not preserve the actual runoff-grid bounds or latitude order. The v5 descriptor now has exactly two Namelist groups: `&DIMINFO` stores model dimensions and bounds; `&INPUTDIM` stores the paired INPMAT name, input-grid dimensions, actual geographic edges, and row ordering. The Parameter input-matrix generator writes the paired descriptor using its explicit runoff-grid settings. Model initialization and per-input runtime readers independently parse and validate both groups. Regional map generation no longer creates a default INPMAT implicitly; the configured Parameter s01 workflow is the single user-controlled producer.

The legacy TXT converter skips DIMINFO in TXT-to-NML mode because old positional files lack required input-grid provenance. The reverse NML-to-TXT path remains available for v4 export and writes the legacy field subset. No inference is made from model geometry. Mekong sample descriptors were updated; matrix values and raster products were not changed.

## Scientific and compatibility impact

No scientific calculation or parameterization was intentionally changed. INPMAT generation retains the existing calculation and output array layout while recording the input-grid settings that define it. Runtime configuration interfaces now require the two-group standard descriptor. Legacy v4 positional files must be regenerated through the configured input-matrix workflow before use by the standard v5 reader; v4 export remains supported.

Checklist completed for scientific assumptions, metadata contracts, source/document consistency, and introduced assumptions.
