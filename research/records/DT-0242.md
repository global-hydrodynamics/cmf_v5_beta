# DT-0242 — Standardize Tutorial Manual Filenames

**Date:** 2026-11-28  
**Branch:** `feature/package-builder`  
**Level:** L0 — Documentation and naming convention update

## Decision and implementation

Each tutorial's `README.md` is the formal, complete learner-facing manual. The shared human development guide is the authoritative location for the naming and migration rule. AI manual-authoring and tutorial-development guidance point to that rule. `tutorial/README.md` remains the framework overview and index. Tutorial-specific `tutorial_design.md` and `design/manual_design.md` remain developer specifications.

The existing learner manuals in Tutorial01 and Guide01 Workflow Example were moved to their directory `README.md` files without editing their contents. Current index, setup, design-tree, root README, and contribution links were updated. Existing Tutorial02 and Tutorial11 README files were retained in their existing roles; Tutorial02 explicitly states that its full learner manual is not yet available, so no new manual was authored. Historical generation records and captured output listings were not rewritten.
