## Scope and implementation

`mek02-2year_netcdf.sh` now requires `CMF_V50_ROOT`, sources the shared Shell
functions, and uses their initialization, step reporting, and completion
reporting. Repository paths use the Shell variable, while the Fortran
NAMELIST's `CMF_BASE` key remains unchanged and receives that root value.
Progress is numbered across preparation and each year's configuration/run.

Simulation configuration and execution behavior were preserved. A pre-existing
local change to the model log extension (`.txt`) was retained. No material new
knowledge gaps were found; functional validation remains with the user under
L0.
