- **Date:** 2026-11-28

- **Area:** Shared and Tutorial-local Guide01 flood-depth visualization
- **Scope:** Update the shared downscaler visualizer for the current Map contract, refresh the physical Guide01 and sample copies, and document copy provenance. Preserve the existing figures, scientific calculation, and rendering style.

## Change

The shared `visualize_flddph.py` now reads map geometry through the maintained
Map metadata reader and uses `location.csv` plus NetCDF `flddif`, `elevtn`,
and `catmxy` layers. The existing Binary tile path remains available when the
standard NetCDF layer is absent. `read_netcdf_tile()` now recognizes the
`elevtn` variable required by the visualizer. The existing coordinate
placement, missing-value masks, two-panel layout, color scale, and rendering
settings are retained.

The updated shared calculator and visualizer were committed as
`04b8e112ba46b78a0789eec170c795d8dfe6810a`. Their physical Guide01 and
`sample_mekong` copies use only local metadata modules at runtime. The Guide01
README and Tutorial Design record the new shared-source commit and the
non-automatic copy-update policy. The `a01` and `v01` map readers already use
current NetCDF products and needed no code changes.

## Validation and limits

See [VR-0296](validation_runs/VR-0296.md). A representative existing Control
event was prepared from the 2000-09-22 output, downscaled to a 360 × 360
one-minute NetCDF, and rendered by both the shared and Tutorial-local
visualizers. The PNGs were visually inspected and matched pixel-for-pixel.
The full paired Control/Deep Channel set of six Guide01 figures was not
regenerated because the Deep Channel output and analysis products were not
available in this working checkout.

The unrelated pre-existing changes to `run-experiment.sh`, two untracked
Guide01 reference scripts, and Tutorial11 files were preserved and excluded
from this task's commits.
