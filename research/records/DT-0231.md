# DT-0231 — Map Explorer uses v5 params.nml geometry

- Date: 2026-11-28.
- Branch: feature/package-builder.
- Start commit: e246d94a3c5d02155c2b908339b41fa5de1ed4af.
- Authorization: maintainer requested Map Explorer support for v5 `params.nml` and designated the work L0.
- Validation: [VR-0278](validation_runs/VR-0278.md).

## Scope and implementation

`map_reader.Geometry.read()` now resolves `params.nml` before legacy
`params.txt` and delegates parsing to `map/tools/code/map_metadata.py`, using
the validated `&GRID` values (`NX`, `NY`, `NLFP`, `RESOLUTION`) and `&DOMAIN`
bounds. Map discovery, launcher checks, session switching, NetCDF center
validation, high-resolution coarse alignment, and Pin geometry identity now
work with the v5 path. If both formats exist, NML remains authoritative; TXT
is only a fallback when NML is absent.

The direct `f90nml` dependency was added to standard, 2024, and 2022 Explorer
requirements because the shared reader imports it. The environment selection
and installation logic was not changed. README and DESIGN now describe the
current metadata contract.

## Compatibility and limits

No display transform, raster format, coordinate formula, or environment setup
logic was intentionally changed. Existing legacy TXT maps remain readable.
Functional validation was not run under L0; user validation remains required.
