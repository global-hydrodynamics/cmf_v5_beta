## Contract and implementation

The existing mapped-cell mask is `nextxy` record 1 not equal to `-9999`. The annual-mean discharge producer writes `-9999` outside that network and clamps negative runoff contributions to zero on mapped cells; therefore zero discharge is valid. The Python channel-parameter program now indexes discharge with the existing mask before evaluating the reference float32 equations. It retains the same coefficients, exponents, offsets, minimum thresholds, and `-9999` output sentinel. Negative or non-finite discharge within the mapped-cell mask is reported as invalid instead of being passed to fractional powers.

Reviewed the input producer, legacy Fortran reference, and map conventions. No material new scientific or architectural gap was found; the task changes evaluation of masked invalid values only and preserves valid-cell values exactly in the tested case.
