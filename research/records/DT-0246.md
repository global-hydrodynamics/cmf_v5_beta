# DT-0246 — Update Tutorial02 visualization for current Map formats

- **Date:** 2026-11-28
- **Branch:** `feature/package-builder`
- **Starting commit:** `72c23610`
- **Area:** Tutorial02 visualization and current Map-format compatibility
- **Scope:** Update only the Tutorial02 visualization code and directly related learner documentation so it reads the maintained Map metadata and NetCDF products. No model execution or Map/data changes.

## Findings and implementation

`v01-network_maps.py` was the only Tutorial02 visualization script with stale
Map-format assumptions. It parsed geometry by fixed line positions in
`params.txt` and `location.txt`, requested the retired `catmx`/`catmy` variables,
and compared loaded NetCDF map values against legacy Binary products. It now
uses the maintained `read_map_geometry()` and `read_location_csv()` readers,
reads high-resolution `catmxx` and `catmyy` from `1min/1min.catmxy.nc`, and
retains the existing one-based index, unassigned-pixel, catchment, and outlet
logic. The Binary cross-check was removed because the figures use current
NetCDF map products and no longer require Binary map copies. The other four
requested scripts had no affected old-format dependencies. README now describes
the NetCDF map products and simulation outputs.

## Validation

See [VR-0294](validation_runs/VR-0294.md). The complete `v00-visualize_all.sh`
workflow generated all seven expected figures in a disposable copy. The four
map figures and three simulation-comparison figures were visually inspected;
no missing layers or coordinate shifts were observed. Pixel comparisons with
bundled reference figures show small canvas-dimension differences (0–6 pixels
per dimension) in the local Matplotlib rendering environment; visual content
remained consistent. The committed `sample_figure/` images and existing
Tutorial02 output data were not modified.
