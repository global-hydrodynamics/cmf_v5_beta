## Change

`convert_inpmat.py` now always generates the paired destination DIMINFO using the source descriptor and destination INPMAT filename. Existing destination metadata is replaced through a temporary file and atomic rename. Source INPMAT and DIMINFO paths are protected from in-place overwrite. Binary/NetCDF raster conversion logic and CLI arguments are unchanged. The format-conversion README documents this behavior.

## Evidence and limits

Focused tests use isolated synthetic map directories. The actual `s14-bin2nc_inpmat.sh` wrapper completed with a pre-existing conflicting destination descriptor; the reverse NetCDF-to-Binary path was exercised directly. Neither test modifies the Mekong map. See VR-0274 for commands and observed results.
