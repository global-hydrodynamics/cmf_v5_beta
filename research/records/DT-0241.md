## Change and result

The mek02 workflow writes annual NetCDF products under
`gosh_test/out/${PROJ}`; with the default project name, the actual files are in
`gosh_test/out/mek02/`. The f01 wrapper and the shared extraction wrapper had
defaulted to the removed root-level `out/mek02-2year_netcdf/`. Their defaults
now point to `gosh_test/out/mek02/`. The existing `--source-dir` override is
preserved, and the README source path was updated. No simulation settings or
output data were changed.

Both Figure workflows ran using the existing Mekong output. Extracted samples
and generated figures were isolated under `/private/tmp`; the repository's
existing samples and figures were left untouched.
