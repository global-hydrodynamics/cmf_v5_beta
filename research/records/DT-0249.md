# DT-0249 — β02 legacy Map-reference audit

- **Date:** 2026-11-28
- **Branch:** `feature/package-builder`
- **Starting commit:** `d94c07d35cc89b82df408113506acdd4275fe57e`
- **Area:** Maintained NetCDF-first workflows and current Map documentation
- **Scope:** Search tracked source, scripts, configuration and current guidance for retired Map paths; fix active maintained workflows that incorrectly require TXT/old NetCDF layouts. Preserve explicit Binary compatibility and historical v4 material.

## Findings and changes

The active duration-analysis workflow in `tools/downscale_flddph/` had retained fixed `params.txt` and `location.txt` reads. Its sample copy had the same issue, and its flood-depth downscaler/visualizer also required the retired TXT files, `netcdf/` base products, or `<resolution>_nc/` high-resolution products. These readers now use authoritative `params.nml`, prefer `location.csv`, and read NetCDF layers from the current map root and resolution directory, while retaining explicit Binary/TXT fallback behavior. The sample remains a physical copy; its maintained `calculate_depth` implementation was confirmed identical to the shared implementation.

Current regionalization guidance, package-data selection documentation, Tutorial02 Map-reader descriptions, and the Tutorial11 regional-map sample README had stale references or described the current NetCDF workflow as pending. These descriptions now use `params.nml`, `location.csv`, root/resolution NetCDF products, and NetCDF INPMAT/DIMINFO where applicable.

## Classification boundary

- **Fixed active references:** duration processing and visualization readers, current package-selection documentation, and current regionalization/Tutorial descriptions.
- **Retained intentional compatibility:** explicit Binary branches in maintained map I/O, conversion tools, CTL generation, package restoration and current readers' TXT fallback where legacy inputs remain supported.
- **Retained historical or standalone Binary workflows:** `map/src/`, `map/tools/code/legacy_fortran/`, archived v4 package script `doc/make_package.sh`, and specialized Binary-only utilities under `etc/` (including Fortran downscaling, levee, upstream-inflow, storage-to-floodstage and n-year flood-depth tools). These are not the maintained NetCDF-first β02 workflows audited here and were not rewritten.
- **Retained historical documentation:** dated migration inventories, research records, old survey/work reports and historical snapshots, including source-era paths. They are not current run instructions.

The audit does not establish that every specialized `etc/` Binary-only workflow has been ported to NetCDF. Users selecting those workflows must provide their documented legacy inputs or restore Binary products; such a future port would need its own component-specific scope.
