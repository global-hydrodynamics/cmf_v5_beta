## Scope and implementation

The run script now resolves Shell paths through `CMF_V50_ROOT`, sources
`tools/cmf_shell_functions.sh`, and uses `cmf_check_init`, `cmf_check_step`,
and `cmf_check_success`. Binary mode reports five stages (including planned
output CTLs); NetCDF mode reports four. The model-facing Fortran NAMELIST key
remains `CMF_BASE` and receives the same repository root. Simulation settings,
inputs, cleanup patterns, output locations, and execution order were retained.

The root `AGENTS.md` now defines explicit L0 as the smallest local fix with
functional validation left to the user, prohibits functional/regression/end-to-
end checks and new tests/fixtures, permits correcting a directly detectable
syntax/compilation issue, and requires stopping if scientific calculations,
data integrity, or established numerical behavior may be affected. The
`large-model-refactoring` Skill, `cama-development` Skill, AI workflow, rules
index, and `gosh_test/AGENTS.md` point to that single authoritative rule.
