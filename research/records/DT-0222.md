## Scope and behavior

The COG planner now removes NetCDF extensions with `Path.stem`, keeping registered source filenames separate from registry identities and stored NetCDF variable names. It resolves NetCDF variable metadata when applicable and supports exact registered single-variable files whose stored variable uses the filename stem. Unmatched wildcard templates are reported separately from concrete missing filenames. `bifprm.nc` remains an intentional exclusion.

No registry entries, scientific data, or existing global COG products were changed.
