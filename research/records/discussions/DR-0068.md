# DR-0068 — Allocation result tables use named CSV

- **Date:** 2026-11-27
- **Task:** [DT-0214](../DT-0214.md)
- **Source:** Maintainer task specification in the active Codex conversation; no stable archive ID.
- **Maintainer review:** Pending.

## Question and context

The maintained v5 allocation programs and downstream workflows used whitespace-aligned TXT products with fixed-width output. The task requested migration of the five allocation-result tables to named CSV while preserving scientific results and leaving v4 and source observations unchanged.

## Evidence examined

- The maintained producers in `map/tools/code/allocate_flow_gauge.py`, `allocate_dam.py`, and `allocate_level_gauge.py`.
- The maintained allocation wrappers, GRDC analysis consumers, Tutorial 11 reader, Mekong sample files, existing Fortran reference fixtures, registry and allocation documentation.

## Alternatives discussed

The task explicitly ruled out a post-processing-only conversion and permanent TXT fallback in normal v5 readers. The selected design is direct CSV output from the existing Python producers with small named-column CSV readers for affected consumers.

## Proposal (not yet a decision)

No separate proposal was made; the format and scope were specified by the maintainer.

## Maintainer decision and rationale

The maintainer directed that five v5 allocation results use standard CSV with one header row, named fields, proper string quoting, retained row order, numeric precision and sentinels. The separate GRanD categories remain separate. Existing legacy algorithms, v4 code, source observations, and external map data remain outside the migration.

## Implementation instruction, if any

Write CSV directly in maintained producers, update active consumers by field name, migrate the Mekong samples only after comparison, document the schemas centrally, and support an empty MLIT allocation as a header-only file.

## Outcome or unresolved questions

Implemented in [DT-0214](../DT-0214.md). No allocation classification or sentinel meanings were changed. Review of this summary remains pending.
