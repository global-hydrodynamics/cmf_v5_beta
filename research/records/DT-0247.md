## Decision and change

Guide01's experiment and event-downscaling paths now read the current Map
products from `map/mekong_15min/`: `params.nml`, root-level individual
NetCDF maps, the paired NetCDF INPMAT and NAMELIST DIMINFO, and
`1min/location.csv` with NetCDF tile layers. The Fortran NAMELIST key remains
`CMF_BASE`; Shell scripts use `CMF_V50_ROOT` and the shared progress helpers.
Control and Deep Channel keep the same experiment settings, with only
`CRIVHGT` differing.

The maintained implementation in `tools/downscale_flddph/` was copied into
Guide01 and its sample directory. Local metadata helper modules are included;
runtime scripts do not import repository Python code or use symlinks. The
copied calculation remains the shared implementation, with local helper
imports and NetCDF elevation support for the visualizer. The copy records its
snapshot provenance and does not receive shared-tool updates automatically.

Manual, design, setup, and downscaler documentation now describe the current
Map contract and local-copy policy. The historical numbered design records
were left intact.
