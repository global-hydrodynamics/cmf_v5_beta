# KG-0038 — Contributing observation IDs at warped support boundaries

- Task: DT-0154. Trigger event: EV-0657. Validation: VR-0200.
- Category: geospatial resampling / observation provenance.
- Evidence: real-data failure followed by source/test analysis; verified.
- AI-authored interpretation; maintainer scientific review remains pending.

## Discovery and question

The first real all-cell validation failed because 2,508 target cells had positive
but tiny valid fractions and zero source-owner ID after direct min/max ID warps;
2,506 cells showed the converse mismatch. The valid fractions in the first set
were approximately 3.2e-8–0.0128. The question was why the ID and area products,
from the same native ownership mask, disagreed at the coverage edge. This was
recorded during implementation, before accepting provenance as correct.

## Verified resolution

GDAL's min/max and area-average reprojection do not necessarily use identical
edge footprints. A categorical owner warp therefore cannot establish the full
set of positive area contributors. The corrected implementation warps each
native owner's binary support with the same average kernel as the valid mask,
then saves minimum/maximum positive contributing indices. Their summed support
matches valid support with maximum absolute difference 5.96e-8. Every valid
cell now has an owner, and every zero-valid cell has zero owner IDs.

The bounds are not an assertion that all intervening IDs contributed. Exact
native ownership and the complete Item-index/asset map remain saved locally.
No flood values or original data were changed to hide this mismatch. The initial
failed log remains in the external workspace; the corrected contracts and
regression fixture are Git-managed.
