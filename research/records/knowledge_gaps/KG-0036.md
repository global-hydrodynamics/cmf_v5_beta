## What was unknown or assumed?

The adopted three-component design specifies goals but does not yet select (1) the official minimal model/reference comparison contract, (2) the first additional-data manifest/version and placement contract, or (3) package file selection and equivalence when creation metadata differ. These are new v5 design decisions, not inferred defects in the scientific equations.

## How was it discovered?

Recorded during documentation adoption on 2026-11-15, before dependent implementation. Sections 3–5 of [the maintained design](../../../docs/development_and_distribution_design.md) require reproducible packages, approved small datasets and independent regression references, while existing component checks, run examples and historical comparisons do not define one complete acceptance contract. The original document leaves concrete dataset selection for confirmation.

## Verified facts

The tracked Mekong sample already occupies ordinary map/inp paths. Existing metadata and CTL checks run, and earlier model executions have separate research evidence. There is no v5 package assembler. The old packager selects v4 paths, and the actual working tree has uncommitted relocation/utility changes. None of these facts establishes the future official regression baseline, data schema, package exclusion list or byte-identical archive requirement.

## Why the gap matters

The regression contract controls numerical acceptance and test cost; the data contract controls compatibility and safe placement; file selection/equivalence controls what the generated product promises. Each blocks only its dependent implementation. Unrelated source/documentation work can continue under its own approved scope.
