## Scope and implementation

Renamed the map-local setting and Python positional argument to
`BIF_OVL_LAYER`. It now counts only `bifori.csv` overland fields; `riv_width`
is always retained separately. Zero is accepted, and a request exceeding the
source's available overland fields is rejected. The workflow README now states
that a value of five selects `riv_width` plus `ovl_width_1` through
`ovl_width_5`.

No scientific formulas, pathway filtering, basin processing, or map products
were changed. Functional validation and map regeneration were intentionally
left to the maintainer under L0. No material new knowledge gaps were found.
