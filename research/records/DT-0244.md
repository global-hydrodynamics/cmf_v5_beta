# DT-0244 — Modernize Tutorial02 experiment scripts and design

- **Date:** 2026-11-28
- **Branch:** `feature/package-builder`
- **Starting commit:** `8c1aad1c8eac2d6d5110772611a8fe080ae938be`
- **Area:** simulation workflow; documentation
- **Scope:** Align the four Tutorial02 experiment scripts and `tutorial_design.md` with the shared CaMa-Flood Shell conventions and current NetCDF map, runoff, input-matrix, output, and Restart formats. The learner README, manual design, and visualization scripts were explicitly out of scope.

## Prior constraint

The experiment scripts independently derived a `CMF_BASE` Shell variable and used local progress/error handling. During the requested functional run, their annual log copy expected `log_CaMa.nml`, while the current model emitted `log_CaMa.txt`; that prevented the script from advancing after a successful model year.

## Change and enabled capability

All four scripts now require `CMF_V50_ROOT`, source `tools/cmf_shell_functions.sh`, use the common initialization/progress/success helpers, and resolve repository inputs and `src_main/MAIN_cmf` from that root. The Fortran NAMELIST key remains `CMF_BASE` and receives the root path. Step numbering accounts for preparation plus configuration and execution for each of four years. Annual log cleanup and archival now match the current `log_CaMa.txt` output. The design document describes the current individual-file NetCDF map contract, NAMELIST metadata, NetCDF runoff matrix and outputs, annual Restart handoffs, and current high-resolution metadata. It explicitly notes that the excluded visualization reader still needs a separate migration.

## Scientific and compatibility impact

No model algorithms, physical settings, dates, timestep, data selections, output formats, or experiment contrasts changed. The only runtime correction beyond path and reporting modernization aligns log-file handling with the current model's actual output name.

## Validation and limits

See [VR-0291](validation_runs/VR-0291.md). Shell syntax passed for all four scripts; the CMF root guard behaved as expected; all 14 required model/map/runoff/input-matrix files were present; and the four experiment configurations matched the approved table. Default was executed for 2000–2003 in an isolated temporary directory. All annual output files, four-year daily record counts, 2001–2004 boundary Restarts, restart chaining, and completion logs were checked. The test verifies this workflow on the available Mekong checkout, not scientific correctness. The three comparison experiments were not rerun.

## Knowledge-gap review

Checklist completed. No material new scientific or architectural gaps were introduced. The current `v01-network_maps.py` metadata-reader mismatch is documented as separate, explicitly out-of-scope work; it does not prevent the requested Default simulation workflow.
