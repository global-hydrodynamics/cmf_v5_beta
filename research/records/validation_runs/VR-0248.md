## Survey Report — Existing behavior and constraints

- The NetCDF-to-Binary converter selected its registry definition from the
  output filename. Its optional `--source-variable` handled a differing
  internal name, but this coupled a custom input filename to special-case
  configuration.
- The Binary-to-NetCDF converter already accepted an exact
  `--reference-binary`; it writes registry variable names independently of the
  output filename. Both paths can therefore share the same standard reference
  semantics with a small NetCDF-to-Binary CLI extension.
- `map_variables.csv` is authoritative and now uses standard `.nc` product
  filenames. The paired Binary compatibility name is derived by replacing the
  extension. No sample-specific registry rows are needed.
- The shared map I/O writer resolved variable names from the output filename
  stem. A generated `*-sample.nc` therefore needed to resolve to its registered
  base product before looking up its internal variable name.
- Read-only `ncdump -h` inspection of the tracked Mekong sample NetCDF files
  showed the current variables are already `subbsn` and `subcol`; no existing
  map data required rewriting.

## Work Report — Implementation

- Added `conv_nc2bin.sh INPUT.nc REFERENCE` and
  `conv_bin2nc.sh INPUT.bin REFERENCE`. The actual filename determines the
  output stem; the registered reference determines dtype, dimensions, variable
  names, and record/layer layout. Existing Python converters retain validation,
  atomic publication, and default overwrite behavior.
- Simplified `s08-sample_nc2bin.sh` and `s18-sample_bin2nc.sh` into short
  educational scripts that print command usage and invoke the generic wrappers.
- Updated `s05-subbasin.sh` to pass `.nc` sample output paths explicitly. The
  NetCDF writer now resolves a `-sample` suffix only when its base stem exists
  as a registered `.nc` product, producing the standard `subbsn`/`subcol`
  variable names.
- Synchronized the wrappers and sample scripts into tracked Mekong and Rhine
  map-local conversion directories. Updated shared and map-local guides,
  registry usage notes, and focused tests. Existing Binary and NetCDF sample
  data were not modified.
