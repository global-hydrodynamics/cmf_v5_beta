## Implemented behavior

- Single fixed coordinate Div above the map displays Lon/Lat to four decimals
  through the existing mousemove JS callback. The coordinate HoverTool is
  removed, so no duplicate/pointer-following tooltip obscures scientific layers.
- GUI labels Bifurcation Channel, Bifurcation Overland and Unit Catchment
  Boundaries retain original internal/JSON keys and scientific classifications.
- Ordinary assignment boundaries are a shared Overlay step rather than part
  of background construction. Any background can use the selected catmxy tile;
  native-only/100,000-edge limits remain, with diagnostics. Missing catmxy
  disables the control and explains why.
- All backgrounds use the same native assignment click route and CatchmentIndex.
  Missing/mixed/outside-tile assignments clear the prior selection; no geographic
  fallback invents a catchment. If the map has no catmxy at all, existing coarse
  selection remains and is explicitly labeled reference/not assigned catchment.
- SelectionState also stores the assigned computational rectangle. A dedicated
  muted blue-gray dashed 1px renderer shows exact params.txt edges, independently
  of the prominent magenta native assignment boundary. Both survive ordinary
  background/style/pan/zoom/preset/tab changes; source changes clear both.
- PNG receives the same complete native boundary and computational edges, plus
  existing selected outlet/cell and downstream link. No viewport-based delineation.
- Inspector GUI distinguishes clicked location, fine pixel, raw catmx/catmy,
  assignment status, selected river cell and downstream connection. Indices are
  labeled 1-based (Fortran) / (1-based, Fortran), while internal arrays stay
  zero-based. Existing programmatic result keys and JSON schema remain compatible.

catmxy maps fine pixels to coarse river cells; nextxy defines coarse downstream
connectivity. Computational rectangles and irregular assigned regions are
scientifically different. The choice of background and sampled raster cannot
change the selected assignment. Existing native geometry handles holes,
disconnected components and tile limits without filling/joining them.
