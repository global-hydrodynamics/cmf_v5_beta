## B. Implementation and restrictions

- map_datasets.py supplies script-relative default/relative paths and shallow
  metadata-only discovery of immediate repository map children. params.txt alone
  does not qualify: MapReader must find a readable supported raster. Tools/src,
  hidden and temporary candidates are excluded. Custom absolute/Unicode/space
  paths and repository-relative GUI paths are supported.
- map_session.py owns Map Dataset controls and one active Explorer per browser
  session. Dropdown/path edits do not load. Load Map locks repeated requests,
  prepares/validates/renders a fresh coherent bundle, then replaces the view on
  the same server. Failure during preparation or Bokeh model mounting restores
  the prior view, controls, selection and Pins. No arrays are swapped in place.
- Pins trigger explicit Switch Map and Clear Pins / Cancel confirmation. Only a
  successful approved replacement clears them. Exported files are never deleted.
  New map-specific caches/extent/settings/selection/Inspector/Gallery/Pins reset;
  application mode/controls remain. Session-local factories prevent cross-tab
  changes. Old instances guard stale callbacks, cancel queued document ticks and
  release reader/network/selection/native/Inspector caches after Panel detaches
  old document models. Session cleanup uses Bokeh's exact callback signature.
- Terminal/direct Python/macOS/native Windows/WSL default to bundled Mekong with
  no folder dialog, retaining explicit map/port/environment/browser options.
  Only bundled Mekong receives compatible p01-f04b startup; other maps show their
  complete native extent with a Custom geographic frame and supported coarse
  raster/network. JSON map mismatch is rejected before state mutation and tells
  users to load that map explicitly first. Same-map v1/v2 remains compatible.
  PNG/JSON names identify the active map and outputs stay outside map inputs.
- hires_netcdf.py validates native coordinate centers/dimensions/orientation,
  explicit variable aliases, dtype, units and missing metadata. catmxx/catmyy or
  catmx/catmy are paired int16 assignments, not reconstructed containment or
  network tracing. Float32 terrain/width/uparea and int8 visual/catmz100 are
  supported; packed/scaled/inconsistent fields are rejected. Native uparea m²
  converts to km²; supplied km² is retained and is distinct from inherited coarse
  uparea. Raw integer missing/unassigned codes are retained.
- NetCDF fields take precedence for matching native tiles. Canonical tile keys
  preserve old same-map JSON IDs. Absent optional NC fields may retain compatible
  Binary; existing Mekong visual/catmz100 need this supplement. Present invalid
  NC fields are unavailable instead of silently falling back. A tile with no
  valid fields is removed from discovery. Generic startup reads only native
  headers/1-D coordinates, not full high-res arrays/statistics. Sampling opens
  and closes NetCDF handles around bounded native row/column reads.
- CatchmentIndex consumes native block sampling for both formats; its exposed-edge
  algorithm, holes/components/pixel edges and full-assignment selection remain.
  P5/P95 masking/weighting/caching, palettes, OSM and PNG share existing science.
  No viewport/display pixel is substituted for native catmxy.

Updated app/controller/reader/launch/config/selection/scene, tests, README/DESIGN
and six scientific-registry usage/evidence rows. All workflow_stage values and
other scientific registry fields remain unchanged. No numerical-model/Gallery
plotting script/input data is changed; generated PNGs stay outside the commit.
