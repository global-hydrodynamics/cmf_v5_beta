## Scientific contracts investigated

Read existing app/docs/tests, root development rules, maintained distribution
boundaries, visualization and river-map guides, f02-f05 implementations, actual
map headers/Binary sizes, map-variable metadata and existing Figure catalog.
Confirmed params 80x120 at 0.25 degrees; location metadata describes 1200x1800
at 1/60 degree. catmxy is two little-endian Int16 planes; visual signed Int8;
elevtn/flddif Float32. All are north-first/X-fastest. -999 assignment pairs are
unassigned land; -9999 other missing; visual codes 10/7 are main/small streams.
Outlets are outlon/outlat geographic degrees. bifprm has 382 paths, five width
layers and integer coarse endpoint indices. Positive first-layer width defines
77 channels; 305 others are overland. All current paths are valid and unique.

Scientific distinctions retained: stored nextxy supplies topology; outlet
segments are symbolic, not observed centerlines; inherited catchment attributes
are not per-pixel physical measurements; basin IDs differ from color categories;
area means contributing area, not discharge; pathway widths do not mean flow;
regional no-incoming nodes are candidates, not confirmed physical headwaters;
maximum eight-neighbor elevation difference is metres, not conventional slope.
Terrain uses exact full-tile P2/P98, square-root and pale-terrain display gamma.
Zero/negative native values are not universally discarded. Raw values and masks
are separate from display normalization. Scientific/map data remain read-only.
