## Dependency / memory investigation

A temporary venv preserves the existing Explorer environment. Unconstrained pip
selected a source Rasterio build requiring absent GDAL build tools; use an available
Rasterio1.4 wheel. netCDF4 1.6.5 wheel requires a compatible NumPy1.x ABI; tested
NumPy1.26.4/Rasterio1.4.1/GDAL3.9.2. Optional independent validator rio-cogeo7.0.4.
README records install instructions and platform/version limits.

Initial RSS-budget tests identified that bounding Python reads/GDAL block cache
alone left large Overview buffers. GDAL overview source/config documentation
establishes the separate work-buffer control. Reduce block cache16MiB, Overview
work chunks2MiB and staging Overview tiles128px; NetCDF caches4MiB globally and
1MiB per data variable; compression threads1. Final16384x8192 Float32 plane512MiB
converts/verifies under a320MiB ps-monitored RSS budget; observed peak162.5MiB.
The monitor kills the child if its budget is exceeded. This is a tested case, not
a universal memory ceiling across platforms/band counts; JOBS multiplies costs.
No full native array is loaded; windows include final partial chunks.
