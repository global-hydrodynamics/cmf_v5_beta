## Trigger and authorization

Maintainer reports Japan→Global loading fails with the large-tile exact P5/P95
cache guard. Initial plan was a supported coarse fallback; maintainer explicitly
permits sparse sampling for visualization and asks to continue. This supersedes

to display range; source values, native assignments and geometry remain exact.
Existing branch, autonomous implementation/verification/commit/push retained.
No source-data/COG generation, converter/package/model/Gallery-script changes.

## Implementation

Tile.percentiles keeps exact full-native assigned P5/P95 at≤50million pixels.
Larger native tiles use twelve equal raster strata on each axis, reading one
centered patch up to16×16 in each stratum:≤144small windows /36,864native pixels.
Valid paired catmx/catmy and coarse bounds exclude sea/unassigned/invalid pixels;
missing/nonfinite field values are excluded. Inherited coarse attributes repeat
for every sampled assigned pixel. This approximates pixel-frequency weighting,
not physical-area weighting. Fixed patches can miss rare/narrow features and are
not claimed unbiased or equivalent to exact quantiles. Neither viewport nor
averaged/nearest display Overview categories define statistics.

Native source helpers read the patches. No whole-native array,full-stat memmap or
global assignment index is allocated. A separate sparse-patches-12-16-v1 policy
keeps approximate cache entries distinct from existing exact entries. Source
signatures/coarse shape/inherited content hash remain cache keys; pan/zoom/style
reuse limits. Native scalar fields and selected boundaries retain original paths.
Manual bounds, Linear/Log and palette interval remain; finite nonpositive samples
enter percentile calculation before the existing Log lower=P5 if positive else
0.01 rule. A sample with no valid assignments still requests Manual instead of
inventing a range. Small exact populations keep existing behavior and caches.

Controls,diagnostics and PNG label approximate P5/P95 explicitly. Global now opens
with the requested p01-f04b rather than failing before adoption. No unrelated GUI
or configuration-schema refactor is introduced. README/DESIGN supersede the old
Manual-only guard; historical records remain intact.
