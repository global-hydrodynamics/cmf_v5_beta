## Rendering and configuration contracts

background_style.py separates physical normalization from palette transfer and
RGBA alpha. Default catchment yellow-green/log and Gallery terrain P2/P98,
sqrt, subdued gray range and pale gamma remain. Explicit Linear accepts zero
and negative terrain; Log masks nonpositive display values, keeps raw values for
inspection and uses positive-only full-tile reference statistics. Difference
remains maximum absolute eight-neighbor elevation difference in metres, not slope.
Automatic terrain limits are full-tile P2/P98, catchment limits are full-coarse-field
physical values, never viewport-fitted. Manual limits must be finite, ordered and
positive for Log. Invalid input keeps the previous valid image and reports an
error; correcting it clears that error. Native source arrays are never modified.
Manual-limit legends now explicitly say manual rather than full-tile reference.

Alpha multiplication preserves original transparent pixels and RGB/colorbar values.
A separate transparent channel image above the base keeps visual10/7 independent
of background opacity. Coarse/none never render it. When catmxy exists, the prior
valid-assignment mask is retained. Without catmxy, visual-only display is allowed
without inferring assignments, while high-res selection remains unavailable.
General assignment boundaries remain independent of channels on both raster types.

JSON remains version2, including files produced by v3. Optional
layers.background_opacity (fraction0..1) and layers.highres_style
(palette/scale/limits; null limits=automatic) persist the active style. Missing
fields retain earlier opacity/defaults or legacy linear/log behavior. V1/v2
compatibility and invalid-load atomicity pass. Presets restore original Gallery
style and opacity100. Per-variable inactive style profiles remain session-local.
