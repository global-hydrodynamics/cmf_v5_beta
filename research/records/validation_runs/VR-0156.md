## Implemented selection contract

- Coarse Raster and No Background select the params.txt grid containing the
  geographic click. The selected cell's complete native assignment mask supplies
  its unit-catchment boundary when available. The clicked fine pixel's assignment
  is reported separately and cannot override this rule.
- Every High-resolution Raster variable selects the native clicked catmx/catmy
  assignment. Missing/invalid/unassigned/outside-tile cases clear grid/catchment/
  point/link highlights, retain clicked/native information and never use geographic
  containment as fallback. Missing catmxy explicitly reports selection unavailable.
- A coarse geographic grid remains valid without catmxy or without matching pixels
  in the selected tile; only the native catchment outline is unavailable.
- SelectionState now records method and geographic containing grid separately
  from native pixel, selected river grid and geometries. Inspector explicitly
  labels Selection method, geographic grid, raw codes and selected river grid
  with Fortran indexing. Selected attributes and nextxy connectivity come only
  from the selected grid; a different native-assigned cell's duplicate attributes
  are not substituted into the selected attributes.
- Rule changes or source/tile changes re-evaluate the last click without requiring
  another click. Variable/style changes under the same rule/source preserve grid
  and cached geometry. Blank background always selects by the coarse default.
  Presets and configuration loads use the same reconciliation path.
- Coarse rectangle, native catchment outline, selected marker/downstream and PNG
  all share the same selected river cell. Existing CatchmentIndex is reused;
  no duplicate polygonization or coarse rectangle substituted for a catchment.

The two rules answer different questions: which computational raster cell was
clicked, versus which river cell owns a native fine pixel. catmxy provides
assignment; nextxy provides downstream connectivity. A display sample is never
used to determine a native assignment or boundary.
