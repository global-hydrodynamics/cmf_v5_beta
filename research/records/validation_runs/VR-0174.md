## Original method and scientific boundaries (superseded below)

New sessions default Auto and target5000 unique visible stored links. Apply an
area cutoff only after viewport/curve clipping and before style computation. The
kth-largest positive finite genuine source-cell uparea (km²) supplies the cutoff;
all links at/above it remain, ties together. Unknown/nonpositive values are never
inferred and remain visible, so target is not a strict cap. Missing uparea disables
filtering with a reason. Periodic seam pieces share source link_index. Pan/zoom
recalculates visible candidates; small views show all tributaries automatically.

The network/nextxy arrays and Inspector remain complete. Selection renderers stay
independent. Full-reference color/width classification populations do not change.
Bifurcation, Channel Pixels, grid and catchment overlays retain separate rules.
This is viewport-dependent display generalization, not scientific topology editing,
watershed delineation or random array striding. Same settings/extent yield the same
segments in browser and PNG; filtered PNG legend discloses actual cutoff/count.

River detail selector Auto/All links; target1000–20000. Presets preserve preference.
Old JSON without optional layers.network_detail/network_budget restores All links
and target5000, preserving historical appearance without schema migration. Invalid
modes/budgets reject before mutation. Source-area cache reuses existing area_style
native values; initial network construction/data loading are still required.

## Knowledge-gap review / limits

No material new scientific or architectural question. UI target5000 is an editable
heuristic, not a physical threshold claimed valid everywhere. Ties/unknown areas
may exceed the target; areas can change density regionally and across zoom levels.
No viewport caching or pixel-density model is introduced. Full global visual QA
and long-duration responsiveness are not claimed. The initial reader/source I/O,
other overlays and existing frame sizing are not optimized by this change.
