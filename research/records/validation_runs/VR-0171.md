## B. Implementation scope and restrictions

- Thin Bash install_package_data.sh and diff_package_data.sh call a shared Python
  standard-library module. Script-relative checkout and logical sibling store
  resolution work from another CWD. --source overrides the store. Its root may
  be a symlink; dataset/destination child symlinks are rejected. No external
  storage location is hard-coded or edited.
- Both operations select the same files, including target-only discovery. Exact
  1min/15sec directory components exclude raw high-resolution Binary while
  retaining their _nc siblings/location.txt. Existing source/build/log/cache
  exclusions are encoded in the one CSV. ELSE_GPCC selects runoff*.nc only.
- Size and1 MiB byte chunks establish IDENTICAL/MODIFIED; absent sides give
  SOURCE_ONLY/TARGET_ONLY. Diff is read-only except an explicitly requested CSV
  report outside all source/target datasets and protected Git paths.
- Import prints Diff before any copy. Global default-No conflict refusal cancels
  all work, including new files. Global Yes defaults to per-file default-No
  approvals. No per-file mode means bulk approval. Missing interactive approval
  stops; --yes approves new files only, --overwrite-all explicitly approves all.
  Dry-run prints the plan and does not prompt/write.
- Selected destinations must be Git-ignored and not tracked paths/ancestors.
  Unsafe/overlapping roots, catalog traversal and non-directory destination
  ancestors fail. No automatic index/ignore modification. TARGET_ONLY is never
  deleted. Identical files skip; ordinary owner-editable files are installed.
- Copy streams to a temporary file in the destination directory, flushes/fsyncs,
  compares content/size against source and atomically replaces only after success.
  Temporary files are removed on errors. Free-space preflight accounts for the
  temporary full copy per filesystem. Detected file metadata changes require a
  fresh comparison. There is per-file safety, not multi-file rollback or a promise
  of transaction isolation from concurrent writers; avoid concurrent data edits.

Only source, tests and documentation are included. No scientific input,
small Mekong fixture, generation algorithm, model, external-store README or real
local data is changed. make_package.sh is not implemented. PACKAGE_DATA_README.md
is updated only inside Git, not copied to the external store.
