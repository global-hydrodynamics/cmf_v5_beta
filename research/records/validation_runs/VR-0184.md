Date: 2026-11-17. Task: DT-0138. Baseline: ce37fc32.

## Request and implementation

Global red terminal diamonds obscure the background. Maintainer requests showing
markers only zoomed in or scaling them, and subtle blue symbols for stored -9
mouths. Show both types only when the viewport spans at most 60 computational
coarse cells on each axis. This geometric threshold is independent of high-res
COG overviews and sampling. Paired (-10,-10) is a 7px red diamond; paired (-9,-9)
is a 6px muted blue #6489AE circle at 70% opacity. Thin white outlines remain.
Both browser sources stay mounted and update/clear with the scene on camera or
network changes. Network Off clears both. No extra settings schema or controls.

Outlet Vector uses stored outlet coordinates; Grid Center uses model-cell
centers. Missing coordinates are omitted/reported; mixed/missing codes do not
become endpoints. No fabricated downstream line. -10 is also used by regional
cutting and is not uniquely an inland-mouth classification. -9 identifies the
stored mouth code; no coastline detection is claimed. River-link arrays,
headwater guides, scientific data, and assignment interpretation are unchanged.
