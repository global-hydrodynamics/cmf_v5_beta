# VR-0238 — Single-Area Allocation Selection and NetCDF I/O

**Date:** 2026-11-26
**Branch:** `feature/package-builder`
**Task:** DT-0194
**Status:** Passed

## Scope

Added a `--single-area` mode to the shared high-resolution selector and used it in the flow-gauge, dam, and level-gauge wrappers in the shared template, Rhine, and Mekong copies. The selector checks the declared area count, resolution tag in the single-area row, and resolution-prefixed `.nc`/`.bin` filenames. Allocation Python retains the final one-area validation. Inspection and representative execution confirmed that its existing logical `.bin` paths resolve through the common map I/O layer to standard NetCDF by default; no Python reader or scientific algorithm change was needed.
