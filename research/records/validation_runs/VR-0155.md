## GUI structure and scientific behavior

Raster Type uses Coarse Raster / High-resolution Raster buttons, followed by
only the relevant independent variable selector. Separate No Background preserves
both types' state without inventing a third raster type. The existing map stays
mounted. background_controls.py adapts GUI choices to the original background /
variable scientific state; it does not render data or reconstruct assignments.

Coarse choices use existing reader/SCHEMA definitions and supplied files: uparea,
basin, bsncol, subcol, elevtn, ctmare, rivlen, rivwth, rivhgt, nxtdst, grdare,
rivman when available. High-resolution choices are tile-specific: Unit-Catchment
(outlet uparea), Elevation, Floodplain Height, and Elevation Difference (8-neighbor).
The catchment option needs catmxy plus coarse uparea; elevation/difference need
native elevtn; flddif also needs elevtn for the documented fill contract. No
missing optional product prevents startup. Supported variables survive source
changes; unsupported selections get a visible named fallback or blank background.
Tile changes retain the existing selection-clear rules. Source selection remains
accessible for independent native inspection/overlays with coarse/blank backgrounds.

Unit-Catchment is inherited coarse uparea through catmx/catmy, in km², using the
Gallery p01-f04 default log/green display. It is not native high-resolution upstream
area and no new watershed is calculated. Native catmxy selection and its distinct
computational rectangle/downstream link remain independent of raster type.

One common Color Settings section shows applicable controls: coarse continuous
palette/scale/limits; categorical fields keep discrete colors with inappropriate
controls disabled; native terrain only exposes gray/pale_terrain and explains
full-tile P2/P98/sqrt/gamma. Fixed catchment palette/normalization controls are
hidden with an explanation, while km² limits remain available. Source status now
identifies the actual native background rather than an inactive coarse field.

Session-local profiles retain colors/limits per type and variable; coarse elevtn
edits do not overwrite uparea and each terrain mode remembers its palette.
Independent variable choices and active style persist in JSON. Inactive style
profiles are intentionally not serialized; after a fresh load they start from
defaults. This limit is documented, not represented as full per-variable persistence.
