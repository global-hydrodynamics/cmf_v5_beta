## Design and scientific boundaries

Bash entry owns fixed editable VER/source setting and disables import bytecode;
standard-library helper shares package_data.load_catalog/files_for/path checks,
1MiB copy_verified and archive atomic no-replace publisher. Existing Import/Diff,
CSV and archive implementation remain byte-identical to baseline. Clean source
is authoritative; no worktree overlay, Git call or re-archive by assembly.

Plan checks provenance/version, major dirs, disjoint inputs/output, required
catalog selections, same-content/differing collisions, policy contradictions
(excluded raw data already in clean source) and conservative free disk space.
Stage on same filesystem; clean bytes/executable modes/internal relative links
preserved, selected Additional Data copied as real files. Verify full union and
contents, then SHA-256 records and final snapshot checks before no-replace publish.
Source/dataset inventories are rechecked; detection is best-effort, not locking.

Manifest inherits source revision/branch; includes builder/code and catalog
hashes, Dataset counts/bytes/content fingerprints, relative per-file size/type/
SHA-256 and total including manifest. Manifest does not checksum itself. Link
checksums hash link text. Store version null is explicit; no version invented.
Relative source reference and package/-directory basis retained; absolute host
paths redacted to basename. No model science or runtime validity inferred.
Redistribution/attribution uncertainties in PACKAGE_DATA_README.md remain open.
Brief knowledge-gap review: no new blocking issue; existing release/permission
and scientific-reference questions remain separate from local assembly.
