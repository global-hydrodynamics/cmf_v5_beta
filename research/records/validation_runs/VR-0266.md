# VR-0266 — Permanent-water wrapper output/reporting regression

- **Validation ID:** VR-0266
- **Event ID:** EV-0852
- **Task ID:** Not assigned; focused correction to an existing map utility.
- **Source commit:** `f265e73ee7c25f72616367452e8c82f0343d7433`; worktree includes unrelated preserved changes.
- **Environment:** macOS arm64; repository CPython 3.12 `.venv`; `s04-permanent_water.sh` run from an isolated temporary map's `script_params/` directory.
- **Dataset:** Git-tracked Mekong 15-minute coarse map with its existing 1min high-resolution NetCDF tile (`location.csv` declares one area). Inputs were symlinked read-only into the temporary map; output stayed under the temporary directory.

## Checks and results

- Before the code fix, ran `s04-permanent_water.sh` with the available Mekong
  1min source. It exited nonzero at the undefined `count` reference. The
  `prmwat.nc` had already been atomically written and closed by
  `write_raster()` before that reporting statement.
- Opened the generated file with NetCDF4 and checked the registered `prmwat`
  variable: shape `(120, 80)` matched map geometry, dtype was float32, units
  were `m2`, `missing_value` was `-9999`, all values were finite, and the file
  was nonempty with no leftover `.tmp` file.
- After replacing `count` with `len(areas)`, reran the same shell wrapper.
  It exited 0 and reported one processed high-resolution area, 6,566 valid
  catchments, 86,319 selected permanent-water pixels, and successful
  `prmwat.nc` output.
- The complete pre-fix and post-fix NetCDF `prmwat` arrays and variable
  attributes compared exactly equal. This confirms the fix changes reporting
  only; aggregation and output content are unchanged.
- `git diff --check` — PASS.

## Interpretation and limits

The exception occurred after permanent-water aggregation and output writing
completed, so the original failure was a false failure report rather than a
partial output. The focused run covers the one-area Mekong 1min NetCDF sample;
no broader map suite or scientific revalidation was run.
