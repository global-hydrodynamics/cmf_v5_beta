## Implementation

- New launch_windows_wsl.cmd, launch_windows_wsl.ps1, launch_wsl.sh and wsl_browser.py;
  shared launch_desktop.py adds no-setup/readiness-gated Windows browser mode, params
  validation and occupied-port diagnostics. WSL default/override and UNC distro
  ownership, drive wslpath conversion, Unicode output encodings, Linux-only Python
  probing, no automatic installation, foreground loopback server, Ctrl-C lifecycle.
- pins.py holds one-based saved river IDs, original clicked lon/lat, mode/tile/map
  identity and cached structured scientific values. Dedicated markers, labels,
  active emphasis, target/mode/source duplicates, list restore, rename/delete and
  off-screen span-preserving navigation. Source metadata/native assignment checked
  before revisit; no containing-grid fallback. Session-only and excluded from JSON.
- Comparison Accordion below diagnostics, full map-column width, retained expansion,
  per-Pin inclusion/order, sticky parameter column and horizontal overflow. All actual
  NLFP thresholds, optional true subbasin IDs, cached regional upstream/bifurcation
  counts and genuine native pixels; inherited uparea labeled separately. No HTML
  parsing or Scene/native rescans during comparison inclusion/rename.
- Pins CSV: all Pins, stable scalar column names and physical units. Comparison CSV:
  included Pins, unique ID/name headers, rows as parameters, all available profile
  and native groups regardless collapse. UTF-8 BOM, Unicode/quotes/newlines, empty
  missing numeric values, timestamped validated output paths and direct downloads.
- Browser and PNG share clicked marker coordinates, labels/colors/active sizes.
  Ordinary Grid, native Catchment and outlet/link selection remain independent.
  PNG deliberately excludes online OSM. CJK fonts are selected where installed.
- Real browser QA discovered a Bokeh document-lock watcher failure and narrow-screen
  Inspector overlap. All Pin widget mutations now use the existing locked schedule;
  scroll children remove Panel's default max-height:100% cap and do not shrink.
  Both fixes have regression tests and were re-inspected in the actual browser.
