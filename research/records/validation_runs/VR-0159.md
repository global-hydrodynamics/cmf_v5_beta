### Representation and compatibility

Overlay is a NamedTuple with explicit dash, never inferred from a legend label.
Three Bokeh sources/renderers use static solid/dashed/dotted DashPatternSpec values;
Channel6/3px and Overland1/3px dots retain thin-line readability and draw order.
Matplotlib uses corresponding absolute patterns at160dpi with dash scaling disabled
locally; ordinary boundaries/centroid guides/grid keep their solid subtle style.
Outlet diameter converts to Matplotlib point area as(size*72/160)². Selected markers
and magenta native boundary are separate and unaffected by ordinary styling.

JSON remainsv2: optional layers.overlays.catchment_boundary_color/outlet_size
load gray/4 when absent. Existing bif_classes remains the saved boolean behind
the newly labelled selector. Preset loader supplies these optional defaults;
CSV entries/classifications are unchanged. Invalid color/size rejected before
mutating the session. Current Gallery colors remain scientifically explicit.

The visible River selector maps labels to shade_rainbow/turbo/Blues/YlGnBu/plasma.
Renderer/config retain legacy palettes; unsupported-in-menu loaded palette remains
rendered under its original ID, with an explicit compatibility message and no
active menu choice. Selecting any of the five replaces it and releases a Gallery
exception. None-aware Select prevents Panel coercing the legacy value to the
first option. Verified direct legacy→Shades_rainbow, not only later menu options.
The original shade_rainbow control table and Background colormaps are unchanged.

MapViewport measures DOM width/window height through ResizeObserver/resize events,
syncs only layout bounds, and sizes one persistent Bokeh plot. Quantize frame
height first then derive width to avoid independent-rounding aspect errors.
Pane/wrapper dimensions track the frame, keeping a narrow plot centered and the
legend below it. Pan/zoom/ranges and export do not read browser image pixels.
