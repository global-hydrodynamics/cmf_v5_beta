# VR-0207 — Downscaler input formats and calculation options

- Event: EV-0680
- Task: DT-0161
- Source commit: `7f09b7b8a1ad4fe0ee83a57b18a9aa6719c28f3a` (tested source was the task's working-tree changes based on this commit; the implementation was committed after validation)
- Environment: macOS workstation; repository `.venv` with Python 3.11, NumPy and netCDF4; Homebrew GNU Fortran.
- Dataset: tracked Mekong `flddph_2001-09-01.nc` snapshot; `map/mekong_15min` NetCDF and Binary layers; tracked downscaled sample; unchanged `etc/downscale_flddph/src/downscale_flddph.F90` basic reference.

## Checks

- Ran six 360 × 360 Mekong cases: NetCDF/NetCDF with default ON/ON, NetCDF input + Binary maps, Binary input + NetCDF maps, then the remaining three Tributary Fill/Permanent Water combinations.
- Compared valid masks and Float32 values against the tracked sample and across both mixed-format runs.
- Compiled and ran the unchanged basic Fortran downscaler, then compared its result with Python Tributary OFF/Permanent Water ON.
- Checked that suffix-based auto selection records Binary input without adding inferred CF time metadata, that NetCDF-first map selection and map source-file metadata are present, and that the package and sample downscaler scripts are identical.
- Checked both Shell wrappers with `bash -n`, compiled both Python source strings without generating repository cache files, ran `git diff --check`, and visually inspected the regenerated sample Figure.

## Results

- Default NetCDF input + NetCDF maps + ON/ON reproduced the tracked sample exactly: 95,543 valid cells and maximum absolute difference 0 m.
- NetCDF input + Binary maps and Binary input + NetCDF maps each matched the NetCDF/NetCDF run exactly, including the valid mask.
- All four option combinations retained 95,543 valid cells. Tributary Fill OFF/Permanent Water ON matched the unchanged basic Fortran output exactly, including the output mask.
- Permanent Water OFF changed 3,331 valid pixels in this sample. The ON case applies the 0.1 m minimum; OFF preserves calculated values below that threshold.
- Automatic input selection correctly chose NetCDF for the `.nc` snapshot and Binary for the `.bin` snapshot. Auto map selection used NetCDF. Output metadata records formats, map source paths relative to `map_directory`, and option flags; Binary input has no inferred timestamp.
- The regenerated standalone-package sample has a white sea/background outside mapped or rendered land data and was visually inspected.

## Interpretation and limits

These are compatibility checks for one Mekong map, snapshot, extent and resolution. Exact agreement supports input-reader and option behavior against the established sample and basic Fortran path; it is not independent validation of the hydrologic method or evidence for other maps, regions, resolutions, input variants, or platforms. No Tutorial, map-conversion, Gallery, model, or Fortran source was changed.
