# VR-0242 — Multi-resolution format-conversion selection: Work Report

DT-0198; EV-0781–EV-0783; starting revision `1f8c1a07`; 2026-11-26.

## Implementation and contract

Added `tools/shell_functions/cmf_select_hires_for_conversion.sh`, exposed by
`tools/cmf_shell_functions.sh`. It reads canonical registry filename templates
and directory entries/location.txt presence only; no raster content is read.
The existing preprocessing `cmf_select_hires_tag` is unchanged.

Shared/Mekong/Rhine s03/s13 now support empty interactive HIRES, named multiple
tags, Enter=coarsest, all, invalid-tag retry, ordered deduplication, one final
confirmation and clean cancellation. Explicit tags skip tag selection; redirected
stdin requires explicit nonempty tags and never prompts. The complete tag list
is passed to Python once with existing VARS/JOBS/compression. Existing Python
options including --no-overwrite are forwarded by the wrappers.

s03 discovers canonical <tag> NetCDF products. s13 follows the Python source
contract: binary/<tag> takes precedence if the directory exists, otherwise
legacy <tag> Binary; location metadata can come from either layout and Python
retains detailed validation. Empty/unregistered-only sources are not offered.

Contrary to the task's initial assumption, reverse NetCDF-to-Binary CLI accepted
only one tag. Added only split/deduplication and per-tag dispatch in main; the
restore algorithm and worker pool are unchanged. Binary-to-NetCDF already
accepts multiple tags and is unchanged.

Removed t03-convert_external_highres.sh from shared/Mekong/Rhine and active guide
references. Users copy the directory to an external map and use s13 via
CMF_V50_ROOT. The former wrapper's multi-map orchestration is intentionally not
replaced. Its manually copied <tag>_nc/location.txt was redundant: Python already
writes <tag>/*.nc. That unused side directory is no longer created. External
packages and existing generated products were not edited.

## Limits and handoff

Selection establishes available names/metadata, not scientific validity; Python
still validates tiles/geometry. An existing standard Binary directory shadows
legacy Binary even if empty, matching current Python behavior. s03 menu uses
canonical <tag> NetCDF directories; the Python CLI's separate legacy <tag>_nc
fallback is unchanged. Reverse CLI dispatches resolutions sequentially with
parallel workers within each; it is not an all-resolution atomic transaction.
No new scientific knowledge gap or data contract was introduced.
