## Implementation / semantics

area_style caches full unique valid-endpoint source-link positive finite min/max.
Repeated values and viewport/headwater suppression cannot shift interval edges.
For N4/6, Linear uses linspace(min,max,N+1); Log uses linspace(log10min,log10max,
N+1), inverted only for physical km² labels. Interior edges enter the next bin;
max stays in final bin. Constant domains stay constant/first color/base width.
Source areas, masks, link coordinates and scientific arrays are unchanged.

River common AREA MAPPING contains independent Area Scale Log/Linear and
Continuous/4 equal intervals/6 equal intervals/Legacy Fixed choices. Color and
width use the selected transform; manual color bounds affect only color, while
width retains full-reference bounds. Legacy Fixed remains Log1..1e6 and disables
scale/limits. Approved shade_rainbow anchors and Gallery color exceptions stay.
Gallery preset application resets Log; Explorer4/6 main classes use this new
range policy, while static Gallery figures retain their documented old methods.

JSON adds optional network_options.area_scale, default Log for older files.
Legacy serialized quartiles/six_log identifiers now mean4/6 range bins; old
four-class loads disclose the semantic update. No schema bump/new metadata table.
Outlet views explicitly discard the Grid-center range cache because valid endpoint
populations may differ; full-reference classes remain stable during navigation.
