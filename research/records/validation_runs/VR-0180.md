## Result and architecture

Existing Tile/Scene/controller paths are extended, not replaced. High-res numeric
COG supplies overview backgrounds and exact native scalar/assignment windows;
model-grid NetCDF remains authoritative for scientific river attributes/topology.
Missing/incompatible COG has explicit field fallback, retaining maps without COG.
COG validation covers layout, EPSG4326, native geometry, dtype/band names, units,
source filename and source mtime. This is not a cryptographic provenance guarantee.

Both fitted physical screen axes (CSS frame × DPR), available internal overview
factors and a2million-output-pixel budget determine display sampling. Closest
logarithmic overview factor is used. Native selection requires factor1 AND no
output decimation AND ≥1physical pixel/native pixel on both axes AND compatible
catmxy COG for all visible participating tiles. Effective Point Select is automatic;
coarse/none/fallback/overview views are Grid. Native COG views are Catchment. The
single existing group reports mode; no independent user override contradicts LOD.

Grid clicks never load native pixel attributes or construct a catchment index.
Catchment clicks read exact full-resolution native pixel, validate both assignment
indices against coarse dimensions, then select assigned coarse science. Sea,
unassigned and mixed-invalid pairs never get a geographic fallback. High-res and
assigned coarse uparea remain different values with explicit km² labels.

Selected boundary extraction uses the native viewport plus one real neighbor halo.
True tile borders/holes/disconnected parts remain; no viewport closing edges are
invented. Only visible native pixels are counted, not whole catchment total/area.
Pan/source changes update geometry and count together; style-only changes reuse
geometry. Orange catchment and lavender Grid remain separate in browser and PNG.
PNG reuses the same composed frame/overview, not a higher-resolution reread.
Pins retain snapshots; incompatible saved mode asks user to adjust zoom instead
of overriding effective LOD. CSV adds assigned_pixel_scope; old columns/JSONv1/v2
remain compatible. Map switching releases old caches; launchers probe Rasterio.

Exact full-native assigned P5/P95 retains prior weighting/masks/nonpositive policy.
It is not computed from overview samples. Bounded block/disk partitioning and tiny
persistent limit JSON outside source maps preserve repeat-session efficiency.
An uncached tile above50million pixels explicitly requests Manual rather than
starting a global scan or fabricating approximate statistics. Raw arrays share
64MiB LRU and ordinary geometry8windows; active selected geometry caches its window.
Callbacks coalesce latest navigation75ms under document lock. Dataset drawer
visibility remeasures height; simultaneous Retina bounds/DPR events are accepted.

Same macOS arm64 workstation, same TE-Japan files, Python3.12.3,NumPy2.5.5,
netCDF4,Rasterio1.4.1/GDAL3.9.2,Panel/Bokeh. Baseline Python sources were extracted
with git show d6ede25f into a temporary directory; branch/worktree never switched.

then the same geographic navigation/actions. Baseline uses its prior1200max-side
sampling; COG uses the physical frame (initial516×516). This is a comparison of

still scan supported native tiles and need disk workspace. Above50million native
pixels without exact cache needs Manual. Multi-tile physical color limits use the

background/science remains on the existing model-grid reader, not base-grid COG.

untracked script_bin2nc copies are preserved and excluded from this commit. No
scientific data,Gallery plotting method/catalog,converter or package definitions

workflow_stage/scientific field is unchanged.
