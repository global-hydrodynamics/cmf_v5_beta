## Statistical compatibility and edge cases

Fresh sessions save optional layers.auto_limits_policy="percentile" in version2
JSON. Explicit catalog presets save "gallery". Old v1/v2 JSON without the field
uses the same compatibility policy for preceding Auto/Gallery reference behavior:
coarse extrema, inherited coarse-cell attribute reference, assigned terrain P2/P98
and preceding Gallery transfer/Log fallback. This preserves existing Explorer
preset behavior and its documented differences from original Gallery figures.
Selecting explicit Linear or Log uses P3/P97 even after a preset; manual bounds
are strictly validated and never silently corrected. UI notes/PNG legend identify
the reference. No changes to shared preset CSV/list, canonical catalog or Gallery
scripts/images. Independent palette-range transformation order is unchanged.

The old ordinary behavior colored nonpositive Log pixels at its lower endpoint.
This task explicitly includes them in the new statistical population, then masks
them only at rendering. Tests assert this requested distinction and unchanged raw
values. No usable ordinary Log upper bound is manufactured. Constant Linear
fields retain the preceding small display-only upper expansion for a usable
continuous colorbar; categorical fields remain discrete.

Tile cache keys include variable, positive-filter flag, quantiles, assigned-pixel-v2,
inherited/native population and coarse dimensions, within each Tile. Ordinary
Linear/Log share the same finite reference cache; Log resolves its floor afterward.
Native/missing/paired-index validation reuses the existing assignment helper.
Block memory remains bounded; disposable disk workspace scales with tile size.
Explicit Linear inherited fields retain legitimate zero-uparea assignments rather
than dropping them through the previous Gallery positive-river display filter.

An invalid coarse layer cannot be revived by a River/Overlay callback, or exported
through the preceding valid DisplayLayer. A valid layer update clears the error
and restores export; tests exercise the complete failure/recovery sequence.
