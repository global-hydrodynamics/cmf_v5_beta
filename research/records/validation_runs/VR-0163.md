## Scientific source audit and algorithms

Registry, CTLs, converter and actual Mekong inspected before implementation.
Mekong fldhgt.bin is384000 bytes =10×120×80×4, little-endian Float32 with layer
records and x fastest; NetCDF fldhgt is Float32(layer,lat,lon), units m, -9999
fill. All10 values at selected64/98 agree exactly between Binary and NetCDF.
NetCDF permutations/reversed spatial axes are normalized by dimension metadata;
wrong dtype/units/layers/order/packing are rejected with diagnostics. Native
layer order is retained. Optional subbsn[-sample] Int32 positive segment IDs
are verified products;0 is unassigned. Mekong sample segmentation uses documented
30000/5000km² thresholds, and is named as a sample product in the UI. subcol and
bsncol remain display categories, never substitute IDs.

UpstreamIndex preprocesses the complete selected nextxy product in O(N) time/
space using iterative leaf peeling. Accumulate populations from upstream trees;
remaining functional-graph cycles share distinct component totals excluding the
selected node. Direct count is graph in-degree (including a stored self-loop);
total always excludes itself. Invalid/mixed/out-of-region edges terminate known
regional reachability. Cache per product; no recursive per-click graph scans,
viewport filtering, outlet-coordinate filtering or uparea/ctmare approximation.
Different product selections update Inspector counts even if graphics are Off.
Outside-region upstream connectivity may be unknown and is explicitly qualified.

Bifurcation incidence reuses Products.bifurcations: valid stored indices/outlets,
all-layer width validity and first-valid directed-pair deduplication. Classification
uses native first-layer width:positive Channel,zero Overland. Incoming/outgoing
counts are independent of rendered line appearances, seam splits and visibility.
