# Instructions for `package/`

Follow the repository-wide rules in [`../AGENTS.md`](../AGENTS.md), especially
the separation of the GitHub repository, Package Additional Data, and generated
distribution packages. Use the [development rules index](../docs/development_rules_index.md)
when work spans components.

For package design, read
[`../docs/development_and_distribution_design.md`](../docs/development_and_distribution_design.md).
For current commands and limitations, read [`README.md`](README.md); for
additional-data selection use [`package_data.csv`](package_data.csv), and for
the Git-managed description of the external data store use
[`PACKAGE_DATA_README.md`](PACKAGE_DATA_README.md). Do not edit the external
additional-data store unless a task explicitly authorizes it.
